📊 設計概述

目標：提升流量和曝光、優化首次訪客體驗、提高訂閱轉換率

風格定位：知識典雅（Editorial & Sophisticated）

核心特質：沉靜、知識感、信任感、高可讀性、精選內容感

  • 精緻的排版和視覺層級
  • 溫暖但莊重的色彩系統
  • 優雅的留白和呼吸感
  • 專業感與親近感的平衡
  • 增強的內容發現機制（相關文章、推薦等）
  • 社區參與工具（評論、收藏、分享）

🎨 4 個設計方向（對比選擇）

每個方向都保持「知識典雅」的核心風格，但在色彩、排版、視覺重點上有所不同，以便你對比選擇最符合品牌氣質的方向。

方向一
暖棕·古典
溫暖棕色 + Georgia 襯線字體 + 經典古書感
方向二
深灰·現代
深灰藍色 + 無襯線字體 + 當代知識感
方向三
純黑·精英
深黑色 + 混合排版 + 高端雜誌感
方向四
土棕·親近
大地色系 + 友善排版 + 學院社群感

建議：方向一（暖棕·古典）最符合你「知識典雅」和「由淺入深」的品牌氣質，同時保持溫暖的親近感。但其他三個方向也值得對比。我會基於你的選擇，為首頁和內容頁設計完整原型。

佈局原則

  • 最大內容寬度：1200px（優化可讀性）
  • 邊距：40px 桌面 / 20px 平板 / 16px 手機
  • 卡片邊距：24px 內側
  • 行高比例：1.7（長文本閱讀）
  • Grid系統：12 列 CSS Grid
  • 分章間距：60px（視覺分隔）

響應式斷點

  • 行動：< 768px
  • 平板：768px - 1024px
  • 桌面：1024px - 1920px
  • 超寬：> 1920px

⭐ 新功能集成

1. 相關文章推薦

位置：文章結尾（Before CTA）

展示：3 篇網格卡片或側邊欄列表

邏輯：相同分類 + 相似標籤 + 編輯精選

好處：增加頁面停留時間、降低跳出率、提升內部導航

2. 評論與討論區

位置：文章結尾（After CTA）

功能：讀者評論、thread 回覆、點讚、審核

整合：Disqus 或自開發評論系統

好處：提升社區參與、 UGC 內容、SEO 加分

3. 文章收藏 / 書籤

位置：文章標題旁邊（♡ 按鈕）

功能：登入用戶可保存、個人化書籤列表

整合：用戶帳號系統

好處：提高用戶粘性、建立回訪習慣

4. 社交分享

位置：文章開頭 + 結尾

平台：Facebook、Line、Twitter/X、LinkedIn、複製連結

好處：提升內容觸及率、自然流量增長

5. 視覺化信息圖表

內容類型：統計圖表、食物對比、流程圖、數據可視化

工具：Infogram、Flourish、自製 SVG

位置：文章正文中間，強調關鍵數據

好處：提升內容吸引力、提高分享率、更專業感

6. 訂閱 / 會員轉換優化

策略：

  • 首頁：上方顯著 Newsletter 訂閱
  • 文章頁：結尾強化 CTA（2-3 個按鈕）
  • 側邊欄：「熱門文章」+ 訂閱卡
  • 彈窗：50% scroll 時輕量級訂閱邀請
  • 頁底：隱藏訂閱連結（不侵擾）

📋 後續步驟

  1. 選擇設計方向：從 4 個方向中選 1 個（或混合元素）
  2. 首頁原型設計：基於選定方向的完整首頁設計
  3. 內容頁設計：單篇文章頁面設計（含新功能）
  4. 互動原型：可點擊的高保真原型（React）
  5. 風格指南：完整的設計系統文檔
  6. 開發交付：HTML / CSS / 組件代碼
