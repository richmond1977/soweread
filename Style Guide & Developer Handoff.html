🎯 設計概述

項目名稱： 潤讀 So We Read 完整重設計

設計方向： 方向四 - 土棕·親近（大地色系 + 友善排版 + 學院社群感）

主要目標：

  • 提升流量和曝光（改善 SEO 和分享能力）
  • 優化首次訪客體驗（清晰的信息架構和視覺層級）
  • 提高訂閱轉換率（多層次的 CTA 和訂閱優化）
  • 增強社區參與（評論、分享、收藏、推薦）

設計哲學

本設計系統遵循「知識典雅」的美學原則：

  • 精緻： 精選內容，精心佈局，精確的細節處理
  • 可讀性： 優化的字體、行高、字號確保舒適閱讀
  • 親近感： 溫暖的色彩和友善的互動方式
  • 信任感： 專業的設計傳達可信的知識來源
  • 教育性： 清晰的視覺層級幫助讀者快速理解

/* 標題 (Headings) */ font-family: 'Georgia', 'Noto Serif TC', serif; /* 正文 (Body) */ font-family: 'Georgia', 'Noto Serif TC', serif; /* UI / 按鈕 */ font-family: 'Helvetica Neue', 'PingFang TC', sans-serif; /* 代碼 */ font-family: 'Courier New', monospace;

元素 字號 重量 行高 用途

排版特性

  • Line-height: 1.8 for body text（優化長文本可讀性）
  • Letter-spacing: -0.02em for headings（更緊湊、優雅）
  • Font-weight: 400 標準 / 600 強調 / 700 加粗
  • Max line-length: ~700px（每行最多 70-80 字）
  • 段落間距： 1.5rem between paragraphs
  • 文本環繞： text-wrap: pretty（更優雅的換行）

佈局原則

  • 最大寬度： 1200px（main container）
  • 邊距： 40px 桌面 / 20px 平板 / 16px 手機
  • 卡片邊距： 24px 內側
  • 分章間距： 60px 上下
  • Grid 系統： 12 列 CSS Grid

CSS Grid 範例

/* 文章網格 - 3 列 */ .article-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(320px, 1fr)); gap: 32px; } /* 側邊欄佈局 - 主內容 + 邊欄 */ .article-layout { display: grid; grid-template-columns: 1fr 300px; gap: 40px; }

卡片組件

所有卡片遵循以下規則：

  • 背景：白色（#ffffff）
  • 邊框：1px solid #e8dfd6
  • 陰影：0 2px 8px rgba(0, 0, 0, 0.06)
  • 圓角：6px
  • 內邊距：24px
  • 懸停狀態：加強陰影 + 平移 -4px

📱 響應式設計

斷點定義

設備 寬度 特性
Mobile < 768px 單列佈局、大觸控目標（44px+）、簡化導航
Tablet 768px - 1024px 2 列佈局、側邊欄移至下方、縮小邊距
Desktop 1024px - 1920px 完整 3 列、主+邊欄、40px 邊距
Ultra-wide > 1920px 固定寬度 1200px、居中、兩側留空

Mobile-First 原則

  • 先設計行動版，再向上擴展
  • 使用 @media (min-width: ...) 進行斷點
  • 觸控目標最小 44×44px
  • 簡化行動版導航（漢堡菜單或簡化菜單）
  • 優化行動版圖片（srcset、webp 格式）
/* Tablet */ @media (min-width: 768px) { .article-layout { grid-template-columns: 1fr; } .article-sidebar { flex-direction: row; } } /* Desktop */ @media (min-width: 1024px) { .article-layout { grid-template-columns: 1fr 300px; gap: 40px; } }

⚙️ 開發指南

HTML 規範

  • 使用 semantic HTML5（main, article, section, aside）
  • 所有非 void 元素必須顯式關閉（<div></div> 不是 <div/>）
  • 所有屬性使用雙引號（<div class="active">）
  • 使用 BEM 命名規則（.block__element--modifier）

CSS 規範

  • 使用 CSS 變數管理色彩和間距
  • 優先使用 CSS Grid 和 Flexbox
  • 使用 rem 單位（基於 16px）而非 px
  • 包含 print styles（@media print）
  • 避免硬編碼色彩值，引用 CSS 變數
:root { --primary: #6b5b4d; --primary-light: #8b7d73; --bg-light: #faf8f5; --bg-medium: #f0ebe5; --text-dark: #1a1a1a; --text-medium: #3d3d3d; --text-light: #666666; --spacing-xs: 8px; --spacing-sm: 12px; --spacing-md: 16px; --spacing-lg: 24px; }

JavaScript / React 最佳實踐

  • 使用 React Hooks（useState, useEffect）管理狀態
  • 為互動元素添加 ARIA 屬性（accessibility）
  • 避免內聯樣式，使用 CSS 類
  • 為所有異步操作添加 loading 狀態
  • 優化圖片加載（lazy loading, srcset）

性能優化

  • 圖片： 使用 WebP 格式，提供 2x 版本用於高 DPI
  • CSS： 最小化，移除未使用的樣式
  • JavaScript： 代碼分割，懶加載組件
  • 字體： 使用 font-display: swap 避免文字閃爍
  • Core Web Vitals： 追蹤 LCP、FID、CLS

無障礙性 (Accessibility)

  • 所有圖片必須有 alt 文字
  • 色彩對比度達 WCAG AA 標準（4.5:1 for text）
  • 鍵盤導航支援（Tab、Enter）
  • 焦點指示清晰可見
  • 表單標籤與輸入關聯（for/id）
